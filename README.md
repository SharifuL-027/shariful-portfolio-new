## ✨ The Vision

This portfolio moves away from standard static templates, introducing a **cinematic, true-black aesthetic** paired with immersive 3D web technologies. It is designed to showcase high-level engineering and modern UI/UX capabilities, offering visitors a buttery-smooth scrolling experience and dynamic visual interactions.

## 🚀 Key Features

*   **Liquid 3D Sphere:** An interactive, mathematically distorted 3D mesh built with `@react-three/fiber` that responds to environment lighting.
*   **Smart Glassmorphism Navbar:** A Framer Motion-powered navigation bar that detects scroll direction—hiding to maximize screen real estate and blurring the background when active.
*   **Lenis Smooth Scrolling:** Studio-freight's Lenis library implementation for a weightless, premium scrolling physics experience.
*   **Cinematic Case Studies:** A masonry-style grid featuring a true-black theme (`#050505`), elegant typography, and slow-zoom image interactions.

## 💼 Featured Case Studies

This portfolio highlights complex, full-stack MERN capabilities, including:
1.  **Field Force & Business Management CRM:** Enterprise-level metric tracking and role-based permissions.
2.  **Bus Ticket Reservation System:** Complex UI logic featuring alphabetical seat row expansion.
3.  **Apparel E-commerce Platform:** Custom variant data models and advanced routing architectures.
4.  **Rose-wood & Evon Projects:** Scalable cloud infrastructure using MongoDB Atlas and Netlify.
